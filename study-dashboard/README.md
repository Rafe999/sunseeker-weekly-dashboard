# 江苏省考 140+ 冲刺看板

个人江苏省考备考可视化与周度诊断看板。

- 在线地址：https://rafe999.github.io/sunseeker-weekly-dashboard/study-dashboard/
- 目标：正式考试 140+，训练目标约 145
- 当前历史水平：总分约 122，行测约 60，申论约 65
- 主要提分方向：行测速度兑现、数量关系/数字推理、申论稳定输出、政治理论/时政长期积累

## 模块

1. **总览**：目标分数、分数 Gap、提分优先级、阶段路线图、时间预算。
2. **周计划**：周一至周日固定训练结构，可在浏览器内打卡。
3. **周六诊断**：录入陌生江苏行测整卷的估分、未做题、数字推理、各模块题数/正确数/用时，自动给出阶段判断。
4. **复盘判断**：录入本周学习时长、套题量、申论训练量、错题二刷率、课程占比，自动判断本周训练结构是否有效。

## 数据保存

当前版本为纯静态页面，打卡与诊断数据通过浏览器 Local Storage 保存在当前设备，不上传服务器。周六诊断支持导出 JSON 备份。

## 发布

仓库使用 GitHub Pages 从 `main` 分支根目录发布。本目录的 `index.html` 推送后会自动更新线上页面。
