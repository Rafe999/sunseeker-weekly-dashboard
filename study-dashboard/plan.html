政治理论 / 时政 / 申论复盘

9月的任务不是把身体压垮，而是建立一个能持续到考试的节奏。10月再把工作日晚间逐步提升到1.5–2小时；11月在身体允许的前提下进入真正冲刺。

每周执行计划

工作日60–90min；周末4–5h

周一

60–90min
图形推理 + 资料10题

图推10–15题，按规律类型复盘，并训练50秒止损；资料10题严格限时，同时记录做到第10题的总时间。

目标：图推稳定性上升；资料10题≤14–15min

周二

60–90min
申论主训练

1道小题严格限时独立完成 → 对材料和参考答案找漏点 → 二次作答。当天不再硬塞大量行测。

目标：提升要点命中率与表达压缩

周三

60–90min
数量关系 + 资料10题

数字推理5题 + 数学运算6–10题；数学运算必须区分“真正做对”和“蒙对”，并训练快速扫题。资料10题再次限时。

数推陌生题≥3/5；数运能迅速筛出可做题

周四

60–90min
言语 / 判断轮换

第1/3周：语句表达 + 篇章阅读；第2/4周：逻辑判断 + 类比。定义判断只保持手感，不再占专项资源。

语句≥1/2；篇章≥3/5；逻辑判断陌生题≥60–70%

周五

≈60min
轻量混合 + 周复盘

20–30道混合限时，维持模块切换感；总结本周正确率最低、最耗时、最需要周末解决的3个问题。

原则：不透支，把问题带到周末解决

周六

4–5h
江苏旧卷 / 准陌生卷 + 深复盘

120min整卷 → 做完补N/F/R熟悉度标签 → 休息20–30min → 数据统计 → 只处理最值得复盘的10–15题。暂不消耗仅剩1–2套完全陌生江苏A卷。

重点记录：资料前10题/20题用时、判断用时、数学运算有效作答

周日

4–5h
申论核心日

A周：150min完整申论 + 约90min复盘；B周：小题深练 + 重写弱题 + 大作文审题/分论点/论证段。

两周形成一个完整申论闭环

工作日碎片

≈60min/天
政治理论 / 时政 / 复盘

早通勤政治理论20–30min；午休申论/错题解析；晚通勤只看服务于当天错题的片段课程。

低认知负荷，不替代晚间高效训练
