政治理论 / 时政 / 申论复盘

9月的任务不是把身体压垮，而是建立一个能持续到考试的节奏。10月再把工作日晚间逐步提升到1.5–2小时；11月在身体允许的前提下进入真正冲刺。

每周执行计划

工作日60–90min；周末4–5h

周一

60–90min
逻辑判断 + 资料10题

逻辑判断15–20题，重点加强削弱、假设、推理；随后复盘错题。资料10题严格限时，控制约14–15分钟。

目标：逻辑≥60%；资料保持速度手感

周二

60–90min
申论主训练

1道小题严格限时独立完成 → 对材料和参考答案找漏点 → 二次作答。当天不再硬塞大量行测。

目标：提升要点命中率与表达压缩

周三

60–90min
数量关系 + 资料10题

数字推理/数学运算8–12题，恢复高频题型并练A/B/C识别；资料10题再次限时。

数推≥3/5；资料10题≈14min左右

周四

60–90min
言语 / 判断轮换

第1/3周：篇章阅读 + 语句表达；第2/4周：图推 + 类比。只做对应专项并复盘。状态好可加一个申论片段训练。

篇章≥3/5；图推/类比逐步≥70%

周五

≈60min
轻量混合 + 周复盘

20–30道混合限时，维持模块切换感；总结本周正确率最低、最耗时、最需要周末解决的3个问题。

原则：不透支，把问题带到周末解决

周六

4–5h
行测整卷 + 深复盘

120min陌生江苏卷 → 休息20–30min → 约60min数据统计 → 60–90min只处理最值得复盘的10–15题。

记录总分 / 用时 / 未做题 / 蒙题 / 资料耗时

周日

4–5h
申论核心日

A周：150min完整申论 + 约90min复盘；B周：小题深练 + 重写弱题 + 大作文审题/分论点/论证段。

两周形成一个完整申论闭环

工作日碎片

≈60min/天
政治理论 / 时政 / 复盘

早通勤政治理论20–30min；午休申论/错题解析；晚通勤只看服务于当天错题的片段课程。

低认知负荷，不替代晚间高效训练
